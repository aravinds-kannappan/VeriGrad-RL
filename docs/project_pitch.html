Project Pitch

VeriGrad RL is an open-source demonstration of RL infrastructure for language-model-style agents.

What it showcases

Research to system

Turns a reward-learning idea into a runnable training loop with logs and checkpoints.

Debuggable rewards

Separates rewards from verifiers so failures can be inspected and tested.

Generalization checks

Measures train and held-out behavior separately with deterministic evals.

Reward-hacking probes

Tests malformed actions, blank outputs, and false-positive verifier behavior.

Reusable interfaces

Environment, rollout, eval, and monitoring layers can support larger LM backends.

Operational hygiene

Config snapshots, JSONL metrics, and CI checks keep experiments reproducible.

Next impressive extension

Add a code-repair environment where the prompt includes a broken Python function and tests, the action is a patch candidate, and the verifier runs tests in a sandbox.

VeriGrad RL is built to make RL experiments easier to trust.
