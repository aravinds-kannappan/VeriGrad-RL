Answer Under Pressure

Capability benchmarks tell you what a model can do. They don't tell you what it will do under pressure. This benchmark measures the second thing: real Anthropic models on real GSM8K problems, scored for deference to a wrong authority, spec-gaming a disclosed grader, and chain-of-thought faithfulness — with confidence intervals and an independent grader-reliability check.

Capability is not the bottleneck. Trust is.

The same real grade-school math problem is posed under three framings. The first measures capability; the other two measure propensity — what the model does when the situation is adversarial or ambiguous.

control

Solve the problem honestly. Establishes baseline accuracy (capability) — the anchor every propensity is measured against.

authority_wrong

A confident reviewer asserts a wrong answer, derived from the real gold value — never invented. Measures deference / resistance-to-redirection (sycophancy).

grader_gameable

The substring grader is disclosed and gaming is explicitly invited. Measures spec-gaming / reward-hacking when it pays to cheat.

Mechanistic analysis — why models defer

Measuring that a model defers isn't enough. Chain-of-thought-level mechanistic interpretability on the real transcripts asks: when a model abandons the correct answer, did its reasoning already compute the right answer and then cave (sycophantic override), or did the pressure corrupt the computation itself (anchored reasoning)?

Model Deference cases Sycophantic override Anchored reasoning Override share
opus-4.843175.0%
sonnet-4.63028293.3%
haiku-4.51614287.5%
Across the lineup, deference is overwhelmingly social, not cognitive — the model computed the right answer and threw it away to agree with authority. That is a worse failure mode than honest miscalculation, and it is invisible to any benchmark that only checks the final answer. Two independent signals (a deterministic gold-in-reasoning check and an LLM judge) classify each case and agree at 94%.

The fully-transparent, activation-level analog lives in verigrad_rl/mech/: a synthetic residual-stream circuit where the same override-vs-corruption distinction can be produced causally by patching named features — the API doesn't expose a real model's activations, so the frontier-model analysis is necessarily at the reasoning-trace level.

Is the ruler trustworthy?

Two independent graders score a dual-labeled subset — a deterministic detector and an independent LLM judge. We report Cohen's κ, not just raw agreement, because raw agreement lies when a behavior is rare.

Correctness

κ = 0.95 · 99% raw agreement · n = 450. Validated.

Deference

κ = 0.97 · n = 150. Almost-perfect agreement. Validated.

Spec-gaming

0 positives in both graders — the propensity didn't occur, so there is nothing to validate. (This is where the check earned its keep.)

The cross-check caught a bug in my own ruler. An earlier version of the deterministic spec-gaming detector flagged 3 "positives" the LLM judge unanimously rejected. All three were the same clock-time answer — "2:00 PM" — that the regex misread as two numbers. The disagreement surfaced the bug; raw agreement alone, at 98%, would have hidden it. After fixing the extractor, true spec-gaming is 0/150 across the lineup.

Reproduce it

Real models, real data, real cost. Every number on this page is computed from logged model outputs — nothing synthetic, nothing hardcoded.

pip install -e ".[llm]"
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env        # gitignored

python -m verigrad_rl.cli propensity --smoke       # ~30 calls, ~$0.10, end-to-end check
python -m verigrad_rl.cli propensity --tasks 150   # full run -> benchmark/results/ + FINDINGS.md
python -m verigrad_rl.propensity.mechanism         # CoT-faithfulness analysis -> MECHANISM.md

The repo also ships a transparent RL-from-verifier baseline: a REINFORCE policy over a fully synthetic residual-stream circuit, used as the controllable, activation-level analog of the analysis above. It is labeled as synthetic throughout — not a real network's internals.
