# Security Policy

VeriGrad RL is a research project and currently does not execute untrusted code.

## Reporting Security Issues

Please do not open public issues for security-sensitive problems. Report them privately to the repository owner.

Include:

- affected version or commit,
- reproduction steps,
- expected impact,
- suggested mitigation if known.

## Safety Scope

The current safety-circuit and biosafety environments are synthetic. They are intended for infrastructure and eval design, not as evidence that a real model or biological screening system is safe.

The biosafety playground must stay non-operational. Do not add real pathogen sequences, wet-lab protocols, biological optimization instructions, or content that would materially enable misuse.
